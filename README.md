# Bnder Notice — نظام البلاغات الميدانية

نظام خفيف لتوثيق الملاحظات الميدانية داخل المسجد الحرام والمسجد النبوي ومتابعتها حتى الإقفال.

| الرابط | الاستخدام |
|---|---|
| `/` | صفحة البلاغ الميداني (للمُبلّغ): المكان، نوع الملاحظة، أوصاف جاهزة، صورة، موقع جغرافي، وإحصائية اليوم |
| `/admin` | لوحة المتابعة (للمشرف): المؤشرات، استعراض البلاغات، الإحالة عبر واتساب، الإقفال، وإدارة الجهات |

التقنية: Cloudflare Worker + ملفات ثابتة + قاعدة D1 (بدون مكتبات أو خطوات بناء).

## خطوات النشر

قاعدة البيانات `bndr-notice-db` جاهزة ومربوطة في `wrangler.toml`، والجداول والجهات منشأة فيها.

1. ارفع **محتوى** هذا المجلد إلى جذر المستودع `turkfaiz/bndr.notice` (يكون `wrangler.toml` في الجذر مباشرة).
2. Cloudflare ← Workers & Pages ← Create ← Import a repository ← اختر `bndr.notice` ← اسم المشروع `bndr-notice` ← Deploy.
3. افتح الـ Worker ← Settings ← Variables and Secrets وأضف:
   - `ADMIN_PASSWORD` (Secret): كلمة مرور لوحة المتابعة. **إلزامي**.
   - `REPORT_KEY` (اختياري): رمز يمنع الإبلاغ إلا من الرابط المعتمد، فيصبح رابط المُبلّغ `https://<النطاق>/?k=الرمز`
   - `SESSION_SECRET` (اختياري): نص عشوائي طويل يقوّي تشفير الجلسات وروابط الصور.
4. افتح `/admin` ← تبويب **الجهات** ← أضف أرقام واتساب ← حفظ.

## التخصيص

- الأماكن، التصنيفات، الأوصاف الجاهزة، واسم الجهة: `public/assets/config.js`
- الشعار: استبدل `public/assets/logo.svg` بالشعار الرسمي (نفس الاسم).
- الألوان والخطوط: `public/assets/theme.css`

## ملاحظات تشغيلية

- الصور تُضغط على جوال المُبلّغ (حتى 1280px) وتُحفظ في D1، ويُرسل للجهة رابط صورة موقّع لا يعمل إلا لذلك البلاغ.
- فتح البلاغ في اللوحة يحوّله تلقائياً إلى «قيد المراجعة»، وكل إجراء يُسجّل في سجل البلاغ باسم المراجع.
- اللوحة تتحدث تلقائياً كل 30 ثانية وتنبّه عند وصول بلاغ جديد.
- إن زاد حجم الصور مستقبلاً يمكن نقلها إلى R2 دون تغيير الواجهات.
